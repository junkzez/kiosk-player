# Kiosk Player — видео-киоск для слабых Android-приставок

Без AndroidX, без ExoPlayer. Голый `MediaPlayer` + `SurfaceView`, аппаратное
декодирование. APK ~60–80 КБ, потребление RAM ~30–40 МБ.

## Что делает
- стартует сам после включения приставки;
- играет все видео из папки `/sdcard/kiosk/` по алфавиту, по кругу;
- пересканирует папку на каждом круге (новые файлы подхватываются без перезагрузки);
- полный экран, чёрный фон, сохранение пропорций (letterbox), экран не гаснет;
- Back / Menu / Recents заблокированы; Home возвращает в плеер (приложение — лаунчер);
- битый или неподдерживаемый файл пропускается автоматически;
- стрелка вправо / MEDIA_NEXT на пульте — следующий ролик.

## Установка
1. Собрать APK (см. ниже) и залить на приставку:
   `adb install -r kiosk-player.apk`
   либо скопировать APK на флешку и поставить файловым менеджером
   (включить «Неизвестные источники»).
2. Создать папку `kiosk` во внутренней памяти и положить туда видео.
3. Запустить приложение один раз, дать разрешение на доступ к памяти.
4. Нажать Home → выбрать **Kiosk Player** → **Всегда**.
   Теперь после перезагрузки приставка сразу уходит в видео.

## Выход из киоска
5 быстрых тапов (или кликов пультом/мышью) в **левом верхнем углу** экрана
за 3 секунды → ввод PIN `1234` → откроются системные настройки.

## Настройки в коде
`app/src/main/java/ua/kiosk/player/PlayerActivity.java`, блок `// settings`:
- `DIRS` — список папок с видео (первая существующая берётся в работу);
- `MUTE = true` — играть без звука;
- `PIN` — код служебного выхода;
- `TAPS_TO_EXIT` — сколько тапов нужно.

## Требования к видео
Кодек: **H.264 (AVC), Main profile, до 1080p, битрейт до ~5 Мбит/с**, звук AAC.
H.265/HEVC, VP9 и AV1 на чипах с Mali-450 либо не поддерживаются, либо идут
софтверно и захлёбываются.

Перегнать под приставку:
```
ffmpeg -i input.mkv -c:v libx264 -profile:v main -level 4.0 -preset slow \
       -b:v 4M -maxrate 5M -bufsize 8M -vf scale=1920:-2 \
       -c:a aac -b:a 128k -movflags +faststart out.mp4
```
Если приставка совсем слабая — `-vf scale=1280:-2 -b:v 2500k`.

## Сборка APK

### Вариант A: GitHub Actions (без установки Android Studio)
1. Залить папку проекта в репозиторий на GitHub.
2. Вкладка **Actions** → workflow `build-apk` запустится сам.
3. Скачать артефакт `kiosk-apk` (внутри `app-debug.apk` / `app-release.apk`).

### Вариант B: локально
Нужны JDK 17 + Android SDK (или Android Studio):
```
gradle wrapper           # один раз, если нужен ./gradlew
./gradlew assembleRelease
```
APK: `app/build/outputs/apk/release/app-release.apk`

## Известные ограничения
- Полностью «неубиваемый» киоск даёт только режим Device Owner
  (`adb shell dpm set-device-owner ua.kiosk.player/.Admin` на чистом устройстве).
  На серых китайских прошивках он часто не ставится, поэтому здесь использован
  вариант «лаунчер + перехват клавиш» — его хватает в 95% случаев.
- Между роликами возможен чёрный кадр 0.3–1 с: это цена одного экземпляра
  MediaPlayer. На 1 ГБ RAM держать два плеера ради бесшовности рискованно.
